# Українська локалізація — 0.9.2-beta

Тестовий випуск текстової локалізації Hogwarts Legacy для ПК. Озвучення не змінюється.

Завантажте **Hogwarts-Legacy-UA-0.9.2-beta.zip**, розпакуйте та скопіюйте `UKRAINIAN_TRANSLATION.pak` у `Phoenix\Content\Paks\~mods` у каталозі гри. Установлюйте із закритою грою; мова тексту — англійська. Детальна інструкція — у README.

Внесено 50 виправлень після редакторської перевірки: зміст, відмінки, число, назви та природність реплік. Усі виправлення звірено зі зібраним паком; структурних помилок немає. Один випадок звертання Леандера ще потребує підтвердження адресата. Це не повне ручне перечитування кожної репліки.

Це бета-версія, а не гарантія відсутності мовних помилок. Надсилайте скриншоти й контекст через Issues.
