# Українська локалізація — 0.9.0-beta

Тестовий випуск текстової локалізації Hogwarts Legacy для ПК. Озвучення не змінюється.

Завантажте **Hogwarts-Legacy-UA-0.9.0-beta.zip**, розпакуйте та скопіюйте `UKRAINIAN_TRANSLATION.pak` у `Phoenix\Content\Paks\~mods` у каталозі гри. Установлюйте із закритою грою; мова тексту — англійська. Детальна інструкція — у README.

Виправлено зауваження тестувальників щодо вітальні факультету, реплік Фіґа й Еверетта, назви «дітані» та окремих ідентифікаторів зображень.

Це бета-версія, а не гарантія відсутності мовних помилок. Надсилайте скриншоти й контекст через Issues.
